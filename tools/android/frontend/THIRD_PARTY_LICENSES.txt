Uncharted: The Nathan Drake Collection for Android (ARM port by RedVorteX-TV)
==============================================================================

This app and its runtime are free software under the GNU General Public License,
version 2 or later (GPL-2.0-or-later). Their sources come from:

- ducvd89's Bloodborne-Android (https://github.com/ducvd89/Bloodborne-Android,
  GPL-2.0-or-later): the Android runtime (the Bionic build, the AHardwareBuffer
  present path, the audio and pad bridges, the touch controller, the GPU driver
  manager and bb-prepare), on which this app is built.
- spacepepperoni's uncharted_Linux, Supermedo's uncharted_pc and bloodborne_pc
  (GPL-2.0-or-later): the Uncharted port this one is based on.
- MaSieS4Fun's ARM_bloodborne_pc: the ARM layer on FEXCore.
- FEX (https://github.com/FEX-Emu/FEX, MIT): FEXCore runs the game's x86-64 code.
- shadPS4 (https://github.com/shadps4-emu/shadPS4, GPL-2.0-or-later): the GPU code.
- FFmpeg (LGPL-2.1-or-later), SDL 3 (zlib), fmt (MIT), Zydis/Zycore (MIT),
  xxHash (BSD-2-Clause), miniz (MIT), Vulkan-Headers (Apache-2.0/MIT),
  Dear ImGui (MIT), VulkanMemoryAllocator (MIT), Boost (BSL-1.0).
- fexdroid (https://github.com/cobrabm12/fexdroid, MIT): the origin of the
  Android app's first display and input bridges, which Bloodborne-Android grew from.
- Menu icons: Material Design icons (Apache-2.0, Google).

GPU drivers: the app carries Turnip builds unchanged (assets/drivers/*.zip) and
installs the one for the GPU when "Automatic" is the GPU driver setting; their notices
are at the end of this file. Mesa: MIT, https://gitlab.freedesktop.org/mesa/mesa.

No game files are included: the player uses their own copy of the game.

FSR 3.1: AMD FidelityFX (MIT) through
FireBurn/FSR-Vulkan.
